## Preview-store caveat (not a T3.0 logic FAIL)

Machine/quote JSON lives under Vercel `/tmp/spares-data`. Each isolate seeds its own user UUIDs. A valid session cookie from isolate A is **Unauthorized** on isolate B (`findUserById` miss). That produced:

- `GET /api/machines` 401 immediately after `GET /api/quotes` 200 and `GET /api/auth/me` 200
- Machine page: **Failed to load machine / You are not signed in** while the header still showed the customer email

Same class of caveat as T1.4. Continuous walk on a warm isolate **did** hold (tray at 04:00, full workspace at 04:10–04:12). Retry storms made hops worse. Protection was not disabled.
